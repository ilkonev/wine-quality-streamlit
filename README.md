# Приложение для оценки качества вина

## Запуск

Версия Python: 3.12.
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Кэширование

Для модели используется `st.cache_resource`: он хранит один и тот же объект на весь сервер без копирования, а модель нужно загрузить один раз и переиспользовать. Для таблиц и массивов (`test.csv`, вероятности на тесте) используется `st.cache_data`: он сериализует результат и возвращает его копию, что безопасно для обычных данных.

Если вызвать `joblib.load` без декоратора, модель будет заново читаться с диска при каждом перезапуске скрипта, то есть при каждом движении ползунка, и приложение будет работать медленнее.
